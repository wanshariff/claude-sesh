          Pairing guide · 7 min read
          
          Why two typefaces fight, and how to make them agree
          
          
          Aina Rahman · October 2, 2026
          
          
          Most bad pairings fail in the same way: two faces that are almost alike, set close together, so the reader notices the difference without understanding it. A serif and a sans with the same x-height and the same stroke contrast look like a mistake. Push them apart in role, and the eye stops comparing them.
          
          
          Contrast in role, harmony in proportion.
          
          
          Let the display face carry the personality and the body face carry the reading. Then check what they share: similar proportions, compatible widths, a weight range that covers every state in your UI. That shared skeleton is what makes the contrast feel deliberate.

          Overview
          A pairing has three roles: a display face for headlines, a body face for reading, and a utility face for code and figures. Kernhue picks each role from a different pool so they never compete.
          Lock any role you already love and generate the others around it.
          
            
          Contrast
          Contrast mode pairs faces from different categories: a serif with a sans, or a display face with a text face. The difference does the work, so neither face has to shout.
          It is the safest mode when you are unsure.
          
            
          Harmony
          Harmony pairs two faces from the same category with different skeletons, like a geometric sans with a humanist sans. It reads calmer, but needs a clear size and weight step between roles.
          
            
          Scale
          The type scale multiplies your base size by a ratio for each heading level. Smaller ratios suit dense product UI; larger ones suit editorial pages.
          
            
          Checks
          Every pairing is checked for category contrast, text suitability and weight coverage before you see it.
          Every color step is graded against white and black text, so you know which shades can carry body copy.

            Why does a shade say "AA lg"?
            It reaches 3:1 but not 4.5:1, so it is fine for large headings and UI parts but too faint for body text. Use a darker step for paragraphs and links.
            
            
            Can I export Adobe fonts?
            Exports reference the family name and your Web Project. Kernhue never copies or redistributes Adobe font files.
            
            
            Contrast or Harmony mode?
            Start with Contrast. Use Harmony when the brand wants one calm voice and you can give headings a clear size step.
